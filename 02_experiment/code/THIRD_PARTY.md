# Third-party boundary

No third-party source code, dataset, pretrained checkpoint, or binary is bundled in this local tree.

The planned cloud-only initialization is the official CROMA radar--optical ViT-B-scale release. Its repository URL, immutable commit, license, checkpoint URL, SHA256, input bands, normalization, resolution adaptation, missing/unexpected keys, and pretraining-geography overlap must be recorded in `02_experiment/reports/pretrained_weight_audit.json` before use.

Copernicus-Bench/BigEarthNet S1/S2 assets remain cloud-only and are not part of the code release. Dataset license inheritance and the exact split manifest remain a pre-acquisition gate.
